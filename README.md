# PathX

O **PathX** é uma plataforma web desenvolvida para conectar candidatos e empresas de forma simples, rápida e eficiente. O sistema permite que usuários pesquisem vagas de emprego, visualizem detalhes das oportunidades e realizem candidaturas, enquanto as empresas podem cadastrar, gerenciar e divulgar suas vagas para encontrar profissionais qualificados.

O nome **PathX** tem origem na palavra inglesa *Path* (caminho), representando a trajetória profissional dos usuários, enquanto o **X** simboliza a diversidade de oportunidades e caminhos disponíveis dentro da plataforma.

## 🚀 Funcionalidades

- Cadastro e login de usuários;
- Pesquisa e visualização de vagas de emprego;
- Candidatura a vagas;
- Cadastro e gerenciamento de vagas por empresas;
- Interface intuitiva e responsiva;
- Conexão entre candidatos e recrutadores em um único ambiente.

## 🎯 Objetivo

Facilitar o acesso ao mercado de trabalho, reduzindo as dificuldades encontradas tanto por candidatos na busca por oportunidades quanto por empresas na divulgação e preenchimento de vagas.

## 📌 Sobre o Projeto

O PathX foi desenvolvido como Projeto Integrador com o objetivo de aplicar conhecimentos de desenvolvimento web e experiência do usuário na criação de uma solução prática para aproximar profissionais e empresas.
